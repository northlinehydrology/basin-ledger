# Examples

Each folder is one place: a config (`basin.toml`) that wires real models for one basin and its water users, a script
that fetches its public data (`fetch.py`), and a short write-up (`README.md`). An example is also a study's starting
point. Private studies are built the same way in the private northline repository, never here.

| Example | Status | What it is |
|---|---|---|
| [synthetic](synthetic/) | built | SWAT+'s Osu_1hru + a small MODFLOW 6 model + a synthetic water user; the tests run on it |
| [plaster-creek](plaster-creek/) | planned | Plaster Creek, Kent County, Michigan, with a data center campus |
